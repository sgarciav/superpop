# KinectGame

# Build

From terminal

Close the Editor first (a project can't be open twice), then:

    cd PoseValidation
    ./build.sh linux      # -> Builds/Linux/PoseValidation.x86_64
    ./build.sh windows    # -> Builds/Windows/PoseValidation.exe  (needs Windows module)

To run the game

    cd PoseValidation/Builds/Linux
    ./PoseValidation.x86_64
