# Test Scripts

## test_mediapipe.py

Let's use MediaPipe

First make sure to download the required model from
[here](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker/index#models). Make
sure to specify which version of the model you downloaded in the script by
defining the `MODEL_PATH` variable.

Execute the script:

    python3 test_mediapipe.py

The `test_mediapipe_3d.py` version also displays the 3D coordinates of the wrists.
