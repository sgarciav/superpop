🚀 QUICK START
────────────────────────────────────────────────────────────────────────────

USING KINECT (Current Setup):
  1. Add JointTrackingManager to scene
  2. Set Tracker Type = "KinectManager" 
  3. Run game (works as before)

USING MEDIAPIPE (New):
  1. Start Python script (sends UDP on port 5005)
  2. Add JointTrackingManager to scene
  3. Set Tracker Type = "MediaPipe"
  4. Run game (tracks from camera)

SWITCH AT RUNTIME:
  JointTrackingManager.Instance.SwitchTracker(
    JointTrackingManager.TrackerType.MediaPipe
  );

🔧 CONFIGURATION
────────────────────────────────────────────────────────────────────────────

In Inspector (JointTrackingManager):
  • Tracker Type: KinectManager or MediaPipe
  • Debug Logging: Enable for troubleshooting

In Inspector (MediaPipeJointManager):
  • UDP Port: 5005 (default)
  • Position Scale: Adjust coordinate scaling
  • Flip Y Axis: Toggle for camera orientation
  • Confidence Threshold: Minimum joint confidence (0-1)


⚡ PERFORMANCE
────────────────────────────────────────────────────────────────────────────
  • Latency: < 100ms (MediaPipe), < 50ms (Kinect)
  • FPS: 30 (Kinect), 30 (MediaPipe - depends on Python)
  • Memory: ~1KB per user per frame
  • Thread-safe: Yes (lock-protected queues)


🐛 TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────

No users detected:
  → Check: Python script running? UDP packets sending?
  → Check: Port 5005 not blocked by firewall
  → Check: Camera accessible (MediaPipe)

Tracker not initialized:
  → Check: Add JointTrackingManager to scene
  → Check: Hardware connected (Kinect mode)
  → Check: Python script running (MediaPipe mode)

Wrong hand position:
  → This is Step 3 (coordinate calibration)
  → Currently needs manual calibration
